> 日期：2026-10-09 ~ 2026-10-10 ｜ 环境：本地开发（平台 PG + api + agent）+ 真实云资源（AGS / COS / VPS PG / CloudBase）

## 0. 一句话结论

**核心业务闭环已全部用真实云资源跑通**：注册登录 → 建游戏（开通库 + 种工作区）→ 多轮对话生成（贪吃蛇）→ 沙盒预览可玩 → 一键发布公网可玩 → 版本落库。
未完成：`apps/web` 前端壳；agent 触发发布、沙盒过期自动重建等支路未单独实测（详见 §5）。

## 2. 逐链路验证结果（含代码引用）

### 2.1 认证（M3）

- **实测**：注册 / 登录 / 刷新（refresh_token → 新令牌）/ JWKS / 无令牌 401 / 内部接口无令牌 403 —— 全部通过。
- **agent 本地验签**：LangGraph graph run 用平台 JWT 鉴权通过（PyJWKClient 按 kid 缓存，不调代验接口）。

| 能力 | 代码 |
|---|---|
| RS256 签发 / 验签 / JWKS / 游戏库口令派生 | `apps/api/app/core/security.py` |
| 注册、登录、刷新端点 | `apps/api/app/api/v1/endpoints/auth.py` |
| JWKS 根路径端点（`/.well-known/jwks.json`） | `apps/api/app/api/wellknown.py` |
| agent 本地 JWKS 验签（`Auth.authenticate`） | `apps/agent/agent/auth.py` |

### 2.2 建游戏（COS 工作区 + VPS 游戏库开通）

- **实测**：`POST /api/v1/games` → 平台库落 `games` + 初始 `game_threads`；
  COS `games/{game_id}/` 种入模板 **18 个对象**（含 `input/.keep` 占位，满足挂载前置条件）；
  VPS PG 幂等开通 `game_{sid}` 库 + `game_{sid}_rw` role（`REVOKE CONNECT ... FROM PUBLIC` 已执行，隔离成立）。
- 连接串按 HMAC 派生、不落库；`provision` 内部接口补测通过（返回派生 DSN）。

| 能力 | 代码 |
|---|---|

| COS 前缀占位 / 模板种入 / 版本包 key | `apps/api/app/gateways/cos.py`（`ensure_game_prefixes`、`seed_workspace`、`version_key`） |
| 游戏库开通（幂等 DDL） | `apps/api/app/gateways/pg_admin.py`（`ensure_game_database`） |
| 命名派生（`sid`、库名、role 名） | `apps/api/app/core/naming.py` |

### 2.3 沙盒（M1 / M2：创建、挂载、初始化、生命周期）

- **实测**：
  - 创建：AGS `Sandbox.create`（`metadata.game_id` + `x-mounts` 子路径挂载 + `envs` 注入 `DATABASE_URL`/`PORT`）；
  - 初始化：`/opt/skills` 解包、依赖装到 `/opt/deps`（**144M，不进 COS 挂载层**）、软链 `/workspace/work/node_modules`；
  - 保活：`npm run dev` 常驻（esbuild watch + node --watch），`/api/health` 200；
  - **暂停 → 恢复**：`pause(keep_memory=False)`；恢复时冷启动，`ensure` 全程 **9.2s** 完成（含服务自动拉起）；
  - 沙盒内 `npm run db:migrate` → **VPS 游戏库建表成功**（沙盒经公网直连 PG）。

### 2.4 生成闭环（M5）：真实多轮对话生成贪吃蛇

- **实测**：
  - 生成轮：`runs` 全流程（平台 JWT → 建图 → ensure 沙盒 → deepagents 写代码/构建）；
  - 产物：`src/{main,textures,ui,audio,layout}.js` + `shared/{snake,logic}.js`（7 个源文件，约 1100+ 行）；
  - 构建：`npm run build` 成功（esbuild 产物 1.3MB）；
  - 自检：CDP 截图确认「菜单 → 开始 → 移动 → 撞墙结束 → 重开」全流程；
  - 追加一轮对话成功（**多轮**成立）；工作区源码实时落 COS（`games/{game_id}/src/**`）。

### 2.5 发布闭环（M6）：打包 → COS → CloudRun → 版本落库

- **实测（seq=7）**：总耗时 **4 分 16 秒**（大头是云端镜像构建）；结果：
  - `GET /api/health` 200、`GET /` 200、`GET /dist/game.js` 200（1.4MB）；
  - 浏览器实测可玩（菜单/开始/移动，截图确认）；
  - `game_versions` 写入：`status=deployed`、`revision=1791616085`、`deployed_at` 非空；`games.public_url` 首次写入并跨版本稳定。
- **发布前校验（规格 §7.4）**：沙盒内真实 `npm run build` + `/api/health` 检查通过后才部署；源码扫描拒绝硬编码 `postgresql://` / `localhost`。
- **注意**：CloudBase 默认测试域名在浏览器首次访问会出现「测试域名提示页」（点「确定访问」），正式上线需绑自定义域名。

## 3. 本次踩坑与修复（对照提交）

| # | 坑 | 现象 | 修复 | 提交 |
|---|---|---|---|---|
| 1 | e2b 对非 0 退出码**抛异常** | 探测初始化标记时直接报错，流程中断 | `AgsGateway.run` 捕获 `CommandExitException`，统一返回 `(code, stdout, stderr)` | `3640afc` |
| 2 | `pgrep/pkill -f "server/index.js"` **自匹配**执行脚本的 bash | 服务"已在运行"误判；重启可能杀掉脚本自身 | 命令模式改 `[s]erver` / `[d]ev.mjs` 转义 | `3640afc` |
| 3 | Playwright CDP 的 WebSocket 不带 query token | `connect_over_cdp` 401 | 连接时补 `X-Access-Token` 头 | `3640afc` |
| 4 | `ensure` 响应缺 `thread_id` | FastAPI 响应校验 500 | 补齐字段（契约对齐） | `e4df893` |
| 5 | esbuild 重建后页面不自动刷新 | 截图自检看到旧画面 | 截图前先 `goto` 游戏页加载最新构建 | `91052e5` |
| 6 | CloudRun 服务名上限 **36 字符** | `game-{game_id}`（41 字符）被拒 `InvalidParameter` | 改 `g-{sid}`（34 字符，仍仅由 game_id 派生）；同步 `AGENTS.md` 与规格 §5.3 | `37ae478` |
| 7 | `DefaultDomainName` **自带 `https://`** | 探测 URL 变成 `https://https://...` → 健康检查永远失败，看起来"部署 10 分钟没完成" | 新增 `normalize_base_url`；实测部署本身仅 ~4 分钟 | `37ae478` |
| 8 | `DescribeCloudRunDeployRecord` **不按时间排序** | 取 `records[0]` 误判"无新部署" | 按 `max(DeployTime)` 取最新，并记录上一轮时间戳排除旧记录 | `37ae478` |
| 9 | `fastapi dev` 热重载 + 被中断的长请求 | 旧进程等待优雅退出 → api 整体卡死（登录都超时） | 本地运行改 `fastapi run`（无热重载）；Makefile 同步 | `37ae478` |
| 10 | agent 过度自测 | 113 轮工具调用撞 recursion limit | prompt 收敛（截图 ≤1、禁自定义测试/像素分析、修复 ≤2、发布需用户要求） | `37ae478` |

> 另：发布期间服务会因 **FULL 替换**短暂下线（实测发布总时长 ~4 分钟，其中含镜像构建），后续可优化（预构建 dist / 异步化发布）。

```bash

make sandbox-assets-publish   # 模板 + skills + init.sh → COS platform/

```

- 生产部署（VPS Docker / Nginx）不在本阶段范围。
