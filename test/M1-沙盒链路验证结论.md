## 对规格的影响

1. **`aio` 是预置类型，无需自建镜像**。文档中"All-In-One 需使用自定义镜像"的说法不准确；创建时只填 名称+类型+网络。镜像级定制（`custom` / envd）留到后期，用于加速冷启动（规格 D6）。
2. **E2B `template` 可填 ToolId**（`sdt-...`），不必使用工具名。
3. **网络模式必须 `PUBLIC`**：`SANDBOX` 不通外网，无法 `pip/npm install`，也无法访问数据库。
4. **NoVNC 必须 `resize=scale`** 才适配浏览器窗口。→ 规格 §6.3 预览要求：前端 iframe 默认带该参数，并提供"适应窗口 / 原始比例"切换。
5. 沙盒内浏览器通过 CDP `https://{host:9000}/cdp?access_token=<t>` 受外部控制，与 NoVNC 展示的是同一 Chromium —— 满足"用户能操作 + 能看 AI 操作"。

## M1b：前端直连嵌入 NoVNC（2026-10-08 追加验证）

- 目标：验证「前端直接 iframe 嵌入沙盒 NoVNC URL（含 `access_token`）」是否可行（开发期方案；安全加固后期再做）。
- 脚本：`test/infra/sandbox/m1b_novnc_iframe_verify.py`

| 检查项 | 结果 |
|---|---|
| `X-Frame-Options` | **无**（不阻止 iframe） |
| `Content-Security-Policy` | **无**（无 `frame-ancestors` 限制） |
| 跨域 iframe 加载（本地 http 页面 → `*.tencentags.com`） | ✅ 渲染成功 |
| NoVNC 会话 | ✅ iframe 内 canvas 正常，标题 `cubebox-:1 - noVNC`（截图 `artifacts/m1b_iframe.png`） |
| websockify（WebSocket） | ✅ 直连成功（画面实时显示沙盒内 Chromium） |
| `resize=scale` | ✅ 生效 |

**结论**：开发期前端可**直接 iframe 嵌入** NoVNC，**无需**后端反代。

⚠️ 注意：该 URL 的 `access_token` 是沙盒**全权限凭证**（文件 / 代码执行 / CDP 均可用），直连方案在多用户场景下不安全；**平台上线前**必须改为后端同源反代（规格 R-PRE-1/2/4，已标注为后期项）。

## 复现步骤

```bash
cd test/infra/sandbox
cp .env.example .env      # 填 E2B_DOMAIN / E2B_API_KEY / AGS_TEMPLATE
uv run --env-file .env m1_verify.py check
uv run --env-file .env m1_verify.py run --keep
# 打开脚本打印的 NoVNC 地址人工确认
uv run --env-file .env m1_verify.py kill <sandbox_id>
```

## 已知问题

- 本机开着 Clash 等代理时，`*.tencentags.com` 会被 DNS 解析到 `0.0.0.0/1` 导致连不通；验证时需关闭代理或放行该域名。
- 沙盒内 `commands.run` 首次 `curl` 轮询可能在服务绑定端口前返回非 0，脚本已容错重试。
- NoVNC 后端**同源反代**（规格 R-PRE-1/R-PRE-2/R-PRE-4）：**已决策推迟**——开发期直接 iframe 嵌入（M1b 已验证可行）；**上线前**必须补上（隐藏 token + 用户鉴权）。
